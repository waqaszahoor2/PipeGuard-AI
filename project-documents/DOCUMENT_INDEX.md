# PipeGuard AI — Project Documents Index

This folder collects the main project documents in one location for convenient review.

## Main documents

- `PROJECT_README.md` — project overview, setup, training, testing and deployment instructions.
- `IMPLEMENTATION_PLAN.md` — implementation sequence and architecture plan.
- `IMPLEMENTATION_REPORT.md` — completed work, checks, model status and remaining manual steps.
- `DATASET_AUDIT.md` — supplied research dataset inspection summary.
- `SECURITY.md` — supported versions, secret handling and incident-response guidance.
- `CONTRIBUTING.md` — contribution workflow.

## Technical documentation

The `technical-docs/` folder contains architecture, API contract, data dictionary, deployment, model card, scientific boundaries, security architecture, testing and user-guide documentation, together with the supplied dashboard references.
