# User Guide

## Dashboard

The dashboard shows labelled demonstration counts, a research network map, a priority
warning, pressure trend, browser-local time and historical dataset timestamp.

## Leak Detection

- **Demo:** sends the included normal or leak fixture to the backend.
- **Manual:** generates inputs from the feature schema. Real prediction requires an approved model.
- **CSV:** validates a CSV up to 4 MB and requires exact expected columns.
- **Future Live:** explains the disabled sensor-to-gateway architecture.

## Pipe Information

Searches a small public Calgary research sample. Pressure and flow are intentionally
shown as unavailable because no valid BattLeDIM-to-Calgary mapping exists.

## Inspection Records

Public users can read demo records. Technician authentication is required to create,
edit or delete findings. AI warnings, observations, confirmed findings and repair
decisions are separate fields.
