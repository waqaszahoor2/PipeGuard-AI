# Contributing

1. Create a focused branch.
2. Keep BattLeDIM and Calgary processing separate.
3. Add tests for behaviour changes.
4. Run frontend lint, type-check, tests and build.
5. Run backend formatting, lint, typing and tests.
6. Never add fabricated model metrics or remove the technician-verification warning.
7. Never commit secrets, raw extracted private data or untrusted serialized models.
